# FitTrainer — мобильное приложение для записи к тренеру

Клиент записывается на тренировку прямо с телефона → запись мгновенно
появляется в кабинете тренера → событие автоматически сохраняется в
календарь телефона клиента (Apple Calendar на iPhone, стандартный
календарь на Android).

## Как это устроено

- **Expo / React Native + TypeScript** — одно приложение с двумя режимами:
  «Я клиент» (форма записи) и «Я тренер» (список записей).
- **Firebase Firestore** — общая база данных в реальном времени. Именно
  благодаря ей тренер видит запись клиента сразу, без обновления страницы —
  это происходит на разных телефонах, поэтому нужен облачный бэкенд, а не
  просто локальное хранилище.
- **expo-calendar** — при записи приложение запрашивает доступ к календарю
  и создаёт событие с датой/временем тренировки и напоминанием за час.

Структура:

```
mobile/
  App.tsx
  src/
    navigation/RootNavigator.tsx      — стек экранов
    screens/RoleSelectScreen.tsx      — выбор роли
    screens/ClientBookingScreen.tsx   — форма записи клиента
    screens/TrainerDashboardScreen.tsx— список записей тренера
    services/bookingService.ts        — чтение/запись в Firestore
    services/calendarService.ts       — добавление событий в календарь
    services/firebase.ts              — конфигурация Firebase
    types/booking.ts                  — типы данных записи
```

## Установка и запуск

```bash
cd mobile
npm install
npx expo start
```

Откройте на телефоне через приложение **Expo Go** (отсканировать QR-код),
или запустите `npx expo run:ios` / `npx expo run:android` для полноценной
сборки.

## Настройка Firebase (обязательно для реальной работы)

Без своего проекта Firebase запись клиента не будет видна тренеру на
другом телефоне (только на одном и том же устройстве в рамках сессии).
Чтобы включить синхронизацию в реальном времени:

1. Зайдите на https://console.firebase.google.com и создайте бесплатный
   проект (тариф Spark).
2. В разделе **Build → Firestore Database** нажмите «Создать базу данных»
   (режим test mode для начала — потом можно ужесточить правила).
3. В разделе **Project settings → Your apps** добавьте Web-приложение и
   скопируйте конфиг.
4. Скопируйте `.env.example` в `.env` и вставьте туда значения:

   ```bash
   cp .env.example .env
   ```

5. Перезапустите `npx expo start`.

### Правила безопасности Firestore (пример)

Чтобы клиенты могли создавать записи, но не могли удалять чужие:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /bookings/{bookingId} {
      allow read: if true;
      allow create: if true;
      allow update: if true; // в проде — ограничить только тренеру (auth)
      allow delete: if false;
    }
  }
}
```

Для продакшена стоит добавить Firebase Authentication, чтобы отличать
тренера от клиентов и защитить возможность подтверждать/отменять записи.

## Разрешения календаря

- **iOS**: при первой записи приложение спросит доступ к календарю
  (текст запроса настроен в `app.json` → `infoPlist`). Событие попадёт в
  дефолтный доступный для записи календарь пользователя — то есть в
  обычное приложение «Календарь».
- **Android**: аналогично запрашивает `READ_CALENDAR`/`WRITE_CALENDAR`,
  при необходимости создаёт отдельный календарь «FitTrainer».

## Что можно добавить дальше

- Расписание тренера (доступные слоты) вместо свободного выбора времени.
- Push-уведомления тренеру о новой записи (Expo Notifications).
- Аутентификация тренера, чтобы кабинет был защищён паролем.
- Отдельный экран «Мои записи» для клиента с возможностью отмены.
