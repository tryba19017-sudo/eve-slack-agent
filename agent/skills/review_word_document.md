# Рецензирование документа Word

1. **Найди файл.** Вложение лежит в `/workspace/attachments/`. Если файла нет,
   попроси прислать `.docx` в этот тред.
2. **Пойми задачу.** Если пользователь не сказал, что проверять, по умолчанию
   делай вычитку: орфография, пунктуация, грамматика, опечатки, явные
   противоречия и неоднозначные формулировки. Смысл и юридическую позицию
   меняй только по прямой просьбе — иначе оставляй примечание с предложением.
   Спроси имя рецензента, только если пользователь хочет видеть своё имя.
3. **Прочитай документ** через `read_docx`. Для длинных документов читай
   порциями (`start`/`limit`), пока не просмотришь всё.
4. **Сформируй правки** одним вызовом `review_docx`:
   - `find` копируй из `read_docx` символ в символ (кавычки «», тире —,
     неразрывные пробелы) и в пределах одного абзаца.
   - Делай `find` минимальным, но уникальным: меняй слово или фразу, а не
     весь абзац, чтобы в Word была видна точечная правка. Если фраза
     повторяется — добавь `paragraph` или `occurrence`.
   - `replace` — замена, `delete` — удаление, `insert` — вставка до/после
     фразы, `comment` — только примечание без правки, `insert_paragraph` /
     `delete_paragraph` — работа с абзацами по номеру.
   - Для неочевидных правок добавляй `comment` с коротким объяснением.
     Для очевидных опечаток примечания не нужны.
   - Не правь текст внутри чужих исправлений (`[+…+]` / `[-…-]`), если об этом
     не просили; при сомнении оставь примечание.
5. **Проверь результат.** Если в ответе есть `failed`, исправь только
   неудавшиеся операции и вызови `review_docx` ещё раз уже на `output_path`.
6. **Отправь файл** через `send_file` и коротко опиши в ответе: сколько правок
   и примечаний, главные замечания (3–5 пунктов). Не пересказывай весь
   документ.

## Принять / отклонить исправления

- «Прими все правки» → `resolve_tracked_changes` с `mode: "accept"`.
- «Отклони правки Ивана» → сначала `read_docx`, возьми точное имя автора из
  `revisions`, затем `mode: "reject"` и `author`.
- «Выключи режим исправлений» → `mode: "none"`, `track_changes: false`.
- После этого отправь новый файл через `send_file`.
