Для продуктового рендера:

1. Уточни: что за продукт (материалы, размер), куда рендер (маркетплейс, сайт, соцсети), нужный формат кадра и фон.
2. Масштаб: модель в реальных размерах (метры), иначе свет и DOF ведут себя неправдоподобно.
3. Свет — начни с классической трёхточечной схемы на area-лайтах:
   - Key: большой софтбокс 45° сбоку-сверху, самый яркий.
   - Fill: с противоположной стороны, в 3–4 раза слабее.
   - Rim/back: сзади, для контура; для глянца и стекла — длинные полосы (strip lights), чтобы получить красивые блики.
   - Дополнительно HDRI студии с низкой интенсивностью для отражений (Poly Haven, бесплатно).
4. Камера: фокусное 50–100 мм (без перспективных искажений), DOF лёгкий; для маркетплейсов — обычно без DOF, продукт целиком в фокусе.
5. Фон: бесшовная циклорама (изогнутая плоскость) или shadow catcher + прозрачный фон (Film → Transparent) для вырезки.
6. Рендер: Cycles, 256–1024 сэмплов + денойзер (OpenImageDenoise), Filmic/AgX, для белого фона — следи, чтобы фон не пересвечивал продукт.
7. Материалы бери из `pbr_material`; добавь лёгкие неровности (roughness-карта с шумом, скосы Bevel 1–2 мм) — идеально ровные края выдают CG.
8. Предложи 2–3 ракурса: фронтальный, 3/4 сверху, деталь крупным планом.
