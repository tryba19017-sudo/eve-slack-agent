# Telegram-бот: 3D-дизайн по планировке квартиры

Бот на фреймворке [eve](https://eve.dev). Пользователь отправляет в Telegram план квартиры (фото, скриншот или PDF). Бот:

1. Разбирает планировку: комнаты, их расположение, двери и окна.
2. Уточняет стиль интерьера: современный, скандинавский, лофт, минимализм, неоклассика, джапанди.
3. Делает дизайн-проект: 3D-вид всей квартиры, затем фотореалистичный рендер каждой комнаты с высоты глаз, и присылает их в чат как фото. Можно прислать скриншот из «Планировки 3D», эскиз или фото-референс: бот сохранит ракурс и расстановку или настроение.
4. Подбирает отделку каждой комнаты: краска, обои, ламели, декоративная штукатурка, молдинги, плитка, пол.
5. Присылает список покупок по комнатам с количеством и ссылками на поиск в Лемана ПРО, Ozon, Wildberries и Яндекс Маркете.
6. По запросу меняет стиль или отделку всей квартиры или одной комнаты.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `agent/agent.ts` | Модель агента (Claude через AI Gateway) |
| `agent/instructions.md` | Поведение бота-дизайнера |
| `agent/channels/telegram.ts` | Telegram-вебхук, приём планов, отправка рендеров через `sendPhoto` |
| `agent/tools/render_3d_design.ts` | Генерация 3D-рендера по плану через модель изображений (по умолчанию `google/gemini-3-pro-image`) |
| `agent/tools/shopping_list.ts` | Список покупок: позиции, количество, ссылки на поиск в магазинах; отправляется в чат HTML-сообщениями |

## Программа «Планировка 3D» (`web/index.html`)

Отдельное приложение в одном HTML-файле, работает в браузере без сервера:

- строит настоящую 3D-модель квартиры (Three.js) с дверьми, окнами и мебелью;
- реалистичная подача: мягкое освещение с отражениями, скруглённая мебель с подушками и ножками, фасады шкафов с ручками, шторы, картины, светильники; режим «Фото» показывает комнату с высоты глаз с потолком и светом, как интерьерную фотографию;
- стиль для всей квартиры и отдельный дизайн для каждой комнаты: свой стиль и свой цвет стен;
- отделка, видимая в 3D: обои (полоска, растительный принт, геометрия), ламели на акцентной стене, декоративная штукатурка, молдинги, плитка под кирпич, плитка; пол: ламинат, паркетная доска, ёлочка, кварцвинил, керамогранит, микроцемент;
- вкладка «Смета»: материалы и мебель по комнатам с количеством (краска, грунтовка, рулоны обоев, панели-ламели, м² пола, плинтус, клей) и ссылками на поиск в Лемана ПРО, Ozon, Wildberries и Яндекс Маркете; выгрузка в CSV;
- редактор плана 2D: комнаты можно двигать и менять размер поверх загруженного плана;
- вкладка «Дизайн-проект»: рендер всей квартиры и каждой комнаты, палитра, материалы, список мебели, рекомендации;
- выгрузка дизайн-проекта одним листом PNG, сохранение и открытие проекта в JSON.

Откройте `web/index.html` в браузере. Автораспознавание плана и «Описание от дизайнера» работают, когда страница открыта как артефакт в Claude; в обычном браузере комнаты задаются вручную.

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Задайте переменные окружения (локально в `.env.local`, на Vercel в Project Settings → Environment Variables):

```bash
TELEGRAM_BOT_TOKEN=123456:ABC...          # токен от BotFather
TELEGRAM_WEBHOOK_SECRET_TOKEN=any-random-string
TELEGRAM_BOT_USERNAME=my_design_bot       # необязательно, нужно для групп
AI_GATEWAY_API_KEY=...                     # или OIDC-токен после `vercel env pull`
IMAGE_MODEL=google/gemini-3-pro-image      # необязательно
```

3. Задеплойте (например, `vercel deploy`) и зарегистрируйте вебхук:

```bash
curl -X POST "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://<your-app>.vercel.app/eve/v1/telegram",
       "secret_token":"'"$TELEGRAM_WEBHOOK_SECRET_TOKEN"'",
       "allowed_updates":["message","callback_query"]}'
```

4. Напишите боту `/start` и отправьте план квартиры.

## Локальная разработка

Нужен Node.js 24+.

```bash
pnpm install
pnpm dev
```

Чтобы Telegram достучался до локального сервера, откройте туннель (например, `ngrok http 3000`) и укажите его URL в `setWebhook`.

Документация eve лежит в `node_modules/eve/docs/` после установки зависимостей.
